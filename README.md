# AnnoLab

> 🎨 Разметка изображений, которая учится на ваших данных прямо во время работы.

> 🪟 **Платформа:** пока доступно **только для Windows**. Linux и macOS — в планах.

---

## 🤔 Что это вообще такое

Представьте себе обычный редактор для разметки картинок — рисуете рамки вокруг объектов, отмечаете «это машина», «это человек», «это кот». Скучно, долго, но нужно для обучения нейросетей.

А теперь представьте, что редактор **сам** предлагает вам рамки, потому что уже обучился на ваших предыдущих картинках. Вы только правите: подвинули, удалили, добавили. А модель в этот момент **продолжает учиться** в фоне на всём, что вы уже разметили. И так по кругу — чем больше размечаете, тем меньше работы.

**AnnoLab** — это и есть такой редактор. Локальный, без облаков, без регистраций, без отправки ваших данных куда-либо. Всё крутится на вашем компьютере. 🖥️

### ✨ Что умеет

- 🖱️ Рисовать, двигать и ресайзить рамки — как в любом нормальном редакторе
- 🎯 Автоматически предлагать разметку обученной моделью YOLO
- 📚 Хранить несколько проектов одновременно
- ⏳ Обучать модель в реальном времени, пока вы размечаете
- 📊 Показывать живые графики (потери, точность, mAP) прямо в сайдбаре
- 💾 Выгружать готовый датасет (`.zip`) и обученную модель (`.pt`)
- 🔒 Работать полностью офлайн

## 📦 Шаг 1. Скачивание и распаковка

1. Зайдите на страницу релизов проекта и скачайте архив `AnnoLab.zip` (или клонируйте репозиторий через `git clone`).
2. Распакуйте архив в удобное место — например, `C:\DatasetYoloManager` или `~/AnnoLab`.

> ⚠️ **Важно:** путь до папки не должен содержать пробелов и кириллицы — так меньше шансов наткнуться на странные ошибки. `C:\My Projects\AnnoLab` — плохо. `C:\DatasetYoloManager` — хорошо.

---

## 🔑 Шаг 2. Создаём `password.txt`

Для входа в приложение используется простой файл с логинами и паролями — **`password.txt`** в корневой папке программы (рядом с `router.exe`).

Формат файла — **одна строка = один аккаунт**, логин и пароль разделены пробелом:

```
pro_smeh lolkek
zima kk
```

- 🔤 **`pro_smeh`** — логин, **`lolkek`** — пароль
- 🔤 **`zima`** — логин, **`kk`** — пароль

> 💡 Можно добавить сколько угодно строк — каждый заведёт отдельный аккаунт со своими проектами. Пустые строки игнорируются. Если файла нет — создайте его вручную через блокнот и сохраните в кодировке UTF-8.

## 🐍 Шаг 3. Ставим Python и зависимости

Если у вас ещё нет Python — самое время его поставить.

### 3.1. Установить Python

1. Идём на [python.org/downloads](https://www.python.org/downloads/) и качаем **Python 3.10 или 3.11** (на 3.12+ иногда бывают проблемы с зависимостями YOLO).
2. Запускаем установщик. **Обязательно** ставим галочку `Add Python to PATH` на первом экране.
3. Жмём `Install Now` и ждём.

Проверить, что всё встало:

```bash
py --version
```

Должно вывести что-то вроде `Python 3.11.x`. Если ругается — перезапустите терминал или переустановите Python с галочкой про PATH.

> 💡 **Проверьте, что работает именно команда `py`** — её вызывает `router.exe` для запуска питоновских воркеров. Если `py --version` не отвечает, установите Python через официальный установщик (он регистрирует `py.exe` — лончер).

### 3.2. Поставить зависимости

Откройте терминал (cmd, PowerShell или Git Bash) и перейдите в папку с программой:

```bash
cd C:\DatasetYoloManager
```

Теперь ставим библиотеки (обратите внимание — через `py -m pip`, чтобы пакеты попали именно в тот интерпретатор, который потом будет использовать `router.exe`):

```bash
py -m pip install --upgrade pip
py -m pip install ultralytics pandas pyyaml
```

> ⏳ Установка займёт 5–15 минут — Ultralytics тянет за собой PyTorch, а он тяжёлый. Это нормально.

### 3.3. (Опционально) GPU-ускорение

Если у вас есть NVIDIA-видеокарта и вы хотите обучать модель быстрее — поставьте CUDA-версию PyTorch:

```bash
py -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
```

Подробнее — на [pytorch.org](https://pytorch.org/get-started/locally/). Если GPU нет — пропустите этот шаг, всё будет работать на CPU (медленнее, но работает).

## 🚀 Шаг 4. Запуск

Для запуска используется файл **`router.exe`** — это «менеджер», который:

- поднимает HTTP/HTTPS-сервер на локальных портах 80 и 443;
- отдаёт статику из папки `static/`;
- **сам запускает питоновские воркеры** под каждый проект — как для обучения (`--projectname ...`), так и для инференса (`--projectname ... --serve`).

Вручную вызывать `python`/`py` для старта сервера **не нужно** — `router.exe` делает это сам через команду `py`.

### Запуск

**Откройте терминал от имени администратора** — порты 80 и 443 привилегированные, без прав администратора Windows их не отдаст. Затем перейдите в папку с программой и запустите:

```bash
cd C:\DatasetYoloManager
router.exe
```

> 💡 Если Windows ругается на неизвестного издателя или блокирует запуск — разрешите выполнение (правой кнопкой по файлу → «Свойства» → «Разблокировать», либо через «Подробнее → Выполнить в любом случае» в окне SmartScreen).

### Что вы увидите в терминале

```
[main] worker script: C:\DatasetYoloManager\test\pythonWorkerTrain\pythonWorkerTrainYolov.py  exists=yes
[Manager] spawn: py -u "...\pythonWorkerTrainYolov.py" --projectname "stalzone"
[Manager] inf spawn: py -u "...\pythonWorkerTrainYolov.py" --projectname "chromeDino" --serve
HTTP  server: http://127.0.0.1:80
HTTPS server: https://127.0.0.1:443
Serving: C:\DatasetYoloManager\test\static
[Manager] inf spawn: py -u "...\pythonWorkerTrainYolov.py" --projectname "stalzone" --serve
```

Как это читать:

- 🧠 `spawn: ... --projectname "stalzone"` — запущен **воркер обучения** для проекта `stalzone`
- 🎯 `inf spawn: ... --serve` — запущен **воркер инференса** для проекта (используется кнопкой «Авто-разметка» в редакторе)
- 🌐 `HTTP server: http://127.0.0.1:80` — по этому адресу открывается интерфейс
- 📁 `Serving: ...static` — откуда раздаются HTML/CSS/JS

Откройте в браузере:

```
http://127.0.0.1
```

(порт 80 по умолчанию, поэтому `:80` в адресе можно не писать). Попадёте на страницу входа — логин и пароль берутся из `password.txt`, который вы создали на шаге 2.

> ⚠️ **Не закрывайте окно терминала**, пока работаете с AnnoLab — `router.exe` держит сервер и воркеры живыми. Остановить всё можно сочетанием `Ctrl + C` в этом же окне.

### 🎬 Первый запуск — что делать

1. Введите логин и пароль из `password.txt` (например, `pro_smeh` / `lolkek`).
2. Нажмите «Новый проект».
3. Дайте проекту имя, загрузите файл `coco.txt` — это просто текстовый файл, где **каждая строка — название одного класса**, например:

   ```
   person
   car
   dog
   ```

4. Если хотите, чтобы проект сразу начал обучаться — поставьте галочку «Активный проект» и настройте параметры обучения (модель, размер изображения, learning rate и т.д.). Если не уверены — оставьте значения по умолчанию.
5. Готово! Открывайте проект — и вперёд размечать. 🎯

## 🎮 Шаг 5. Как пользоваться (кратко)

| Действие | Что делает |
|----------|-----------|
| 🖱️ **ПКМ + протянуть** | нарисовать рамку (выберите сначала класс в сайдбаре!) |
| 🖱️ **ЛКМ на рамке** | перетащить её |
| 🔲 **8 точек по краям** | изменить размер |
| 🖲️ **Колесо мыши** | зум |
| 🖱️ **ЛКМ по пустому месту** | панорама |
| ⌨️ **Клавиша `A`** | запустить авто-разметку текущей моделью |
| ⌨️ **`Delete` / `Backspace`** | удалить выделенную рамку |
| ↔️ **Стрелки на экране** | переключение между картинками |

Слева в сайдбаре — список классов и графики обучения. Справа — панель параметров. Пока вы размечаете, модель потихоньку учится и через несколько десятков картинок начинает предлагать всё более точные рамки. 🧠
